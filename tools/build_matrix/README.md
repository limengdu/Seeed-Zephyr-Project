# tools/build_matrix

## English

This directory contains the build matrix runner and its latest result record.

The build matrix proves which board targets and baseline samples compile against
the pinned Zephyr baseline. Over time, it should move from generic upstream
samples toward repository-owned examples and projects.

## 中文

这个目录保存构建矩阵运行器和最近一次结果记录。

构建矩阵用于证明哪些 board target 和基线样例能在固定 Zephyr 基线下编译。后续它应从通用上游 sample 逐步转向本仓库自己的示例和项目。
