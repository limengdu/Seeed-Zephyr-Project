# tools

## English

This directory contains maintainer-facing tools.

Tools validate metadata, run build matrices, provide CLI implementation code,
synchronize derived status, and support CI. User-facing entry scripts should
usually live in `scripts/`.

## 中文

这个目录保存面向维护者的工具。

工具用于验证 metadata、运行构建矩阵、保存 CLI 实现代码、同步派生状态并支持 CI。面向用户的入口脚本通常应放在 `scripts/`。
