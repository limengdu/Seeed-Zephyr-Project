# tools/validate_metadata

## English

This directory contains metadata validation tooling.

Use it to check that board, Grove module, and expansion-board metadata files
remain structurally valid before committing changes.

## 中文

这个目录保存 metadata 校验工具。

在提交改动前，用它检查开发板、Grove 模块和扩展板 metadata 文件结构是否仍然有效。
