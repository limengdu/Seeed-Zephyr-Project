# metadata/expansion_boards

## English

This directory contains authored metadata for XIAO expansion boards.

Expansion-board metadata should describe product-facing identity and visible
ports. Zephyr shields or overlays should own pin-routing truth when applicable.

## 中文

这个目录保存 XIAO 扩展板的人工编写 metadata。

扩展板 metadata 应描述面向产品的身份信息和用户可见端口。适用时，引脚路由事实应由 Zephyr shield 或 overlay 拥有。
