# metadata/grove_modules

## English

This directory contains authored metadata for Grove modules.

Each file should identify one module, its interface, default address when
applicable, related Zephyr driver/configuration, and supported example or project
plans.

## 中文

这个目录保存 Grove 模块的人工编写 metadata。

每个文件应标识一个模块，包括接口、适用时的默认地址、相关 Zephyr driver/config，以及支持的示例或项目计划。
