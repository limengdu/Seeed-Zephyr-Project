# 开发板说明

## English

This directory contains board-specific user notes for XIAO boards.

Use these documents for board behavior that is too specific for the general
Getting Started guide, such as flashing behavior, serial monitor behavior,
bootloader entry, and board-specific validation notes.

## 中文

这个目录保存 XIAO 开发板的专门说明。

如果某个开发板的烧录行为、串口日志、bootloader 进入方式或验证结论太具体，
不适合放进通用入门指南，就放在这里。
