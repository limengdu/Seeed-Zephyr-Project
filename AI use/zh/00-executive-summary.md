# 执行摘要

## 1. 使命

Seeed Zephyr Base 的目标，是成为 XIAO + Grove 在 Zephyr 生态里的入口。

它要建设:

- 精选的 XIAO 开发板最小功能示例库
- 精选的 Grove 模块示例库
- 完整的 XIAO + Grove 项目合集
- 展示每块板子和模块能力的能力目录
- 证明什么能构建、什么能在真实硬件运行的验证证据
- 面向社区贡献示例和项目的入口
- 建立在上述资产之上的未来 CLI 和 VS Code 工具

本仓库中的工具，应按它们帮助用户发现、构建、验证、改造或贡献示例/项目的能力来评价。

一句话总结: 核心产品是经过验证的 XIAO + Grove Zephyr 示例和项目中心，工具围绕它建设。

## 2. 战略方向

方向是:

```text
Zephyr-first, with the right ecosystem for each user path.
```

Zephyr 是示例、可复用项目结构、验证和未来工具的共享基础。Arduino、MicroPython、CircuitPython、供应商 SDK 和 PlatformIO 在更适合用户时仍然保留。

目标是让 XIAO 用户从开发板、Grove 模块、能力或项目想法出发，快速找到可运行的 Zephyr 路径。

一句话总结: Zephyr 是默认基础，但产品从 XIAO/Grove 用户需求开始。

## 3. 本仓库拥有的职责

本仓库拥有围绕上游 Zephyr 的 Seeed 产品层:

- GPIO、I2C、UART、ADC、PWM、USB、BLE、Wi-Fi、display、storage、low power 等板级能力示例
- Grove 模块示例，例如基础传感器读取、执行器控制、显示输出和通信模块
- 组合开发板、Grove 模块、扩展板和真实场景的完整项目
- 开发板、模块、扩展板、模板、示例和项目的 metadata
- 从构建和硬件测试派生出的验证日志与状态
- 用于列出、构建、验证、生成和贡献示例/项目的脚本与未来 CLI
- 位于 `AI use/` 下的 AI 项目纲领

一句话总结: 上游 Zephyr 拥有操作系统，本仓库拥有它之上的 Seeed XIAO + Grove 验证体验。

## 4. 产品质量标准

每个重要新增内容都应强化至少一种可复用项目资产:

- 可构建示例
- 完整项目
- 已文档化能力
- 验证证据
- 改善发现能力的 metadata
- 让示例可审查的贡献路径

一句话总结: 当仓库新增或强化用户和贡献者可复用的资产时，它就在变好。

## 5. 路线图

### 阶段 1: 示例、项目、元数据与验证基础

建设用户和维护者可信的仓库资产:

- XIAO 开发板最小功能示例
- Grove 模块示例
- 扩展板示例
- 首批完整项目
- 开发板、模块、示例、项目和模板 metadata
- 构建与部分硬件测试验证矩阵
- 外部贡献示例的规则

### 阶段 2: 用于发现、构建、验证和生成的 CLI

建设确定性的 CLI，使其可以:

- 列出开发板、模块、能力、示例和项目
- 从项目根目录构建仓库示例
- 验证 metadata 和示例结构
- 从已知示例和模板创建新项目
- 支持 CI 和未来 AI 工作流

### 阶段 3: VS Code 产品体验

建设 VS Code assistant，使其可以:

- 浏览支持的开发板、Grove 模块、能力、示例和项目
- 按开发板、模块、接口和验证状态筛选示例
- 预览接线和配置
- 从仓库资产生成项目
- 将 build、flash、monitor 和 debug 交给官方 Zephyr 工具

一句话总结: 示例和项目先行；有了真实内容，生成器和插件才有东西可生成、可浏览。

## 6. 商业价值

价值在于:

- 降低支持新 XIAO 开发板的成本
- 减少重复 Grove 文档工作
- 让 XIAO 上的 Zephyr 学习路径更清晰
- 让示例跨芯片复用
- 给社区贡献提供可验证入口
- 给专业用户更强的证据
- 提供从最小示例到完整项目、再到生成项目的路径

一句话总结: 价值是一套持续增长、经过验证的知识和示例基础，它减少重复工作并增强用户信心。

## 7. 决策标准

只有当用户越来越能在本仓库里完成以下事情时，项目才算走在正确方向上:

1. 找到某块 XIAO 开发板能力的示例。
2. 找到 Grove 模块示例。
3. 不用手动去上游 Zephyr samples 里寻找，就能构建示例。
4. 烧录一个已知可用的示例。
5. 明白结果是 build-only 还是 hardware-tested。
6. 把示例改造成项目。
7. 贡献一个可以被验证的新示例或新项目。

一句话总结: 成功由有用且经过验证的示例和项目衡量。
