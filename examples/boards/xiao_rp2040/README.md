# xiao_rp2040

## English

This directory contains board demos for Seeed Studio XIAO RP2040.

The baseline demo is `blinky`, which verifies the board target, GPIO stack,
on-board LED alias, and USB CDC serial console under the pinned Zephyr baseline.

## 中文

这个目录保存 Seeed Studio XIAO RP2040 的开发板 demo。

基线 demo 是 `blinky`，用于验证 board target、GPIO 栈、板载 LED alias 和 USB CDC 串口输出能在固定 Zephyr 基线下工作。
