# xiao_nrf52840 blinky

## English

This demo toggles the board LED through Zephyr GPIO. It is the baseline demo for
Seeed Studio XIAO nRF52840.

Build from the repository root:

```sh
bash scripts/build-example.sh examples/boards/xiao_nrf52840/blinky
```

## 中文

这个 demo 通过 Zephyr GPIO 翻转板载 LED，是 Seeed Studio XIAO nRF52840 的基线 demo。

从仓库根目录构建:

```sh
bash scripts/build-example.sh examples/boards/xiao_nrf52840/blinky
```
