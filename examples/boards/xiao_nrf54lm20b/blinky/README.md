# xiao_nrf54lm20b blinky

## English

This demo toggles the board LED through Zephyr GPIO. It is the baseline demo for
Seeed Studio XIAO nRF54LM20B and is signed for the factory MCUboot loader.

Build from the repository root:

```sh
bash scripts/build-example.sh examples/boards/xiao_nrf54lm20b/blinky
```

## 中文

这个 demo 通过 Zephyr GPIO 翻转板载 LED，是 Seeed Studio XIAO nRF54LM20B 的基线 demo，并针对出厂 MCUboot 加载器签名。

从仓库根目录构建:

```sh
bash scripts/build-example.sh examples/boards/xiao_nrf54lm20b/blinky
```
