# xiao_samd21

## English

This directory contains board demos for Seeed Studio XIAO SAMD21.

The baseline demo is `blinky`, which verifies that the board target, GPIO stack,
and on-board LED alias build under the pinned Zephyr baseline.

## 中文

这个目录保存 Seeed Studio XIAO SAMD21 的开发板 demo。

基线 demo 是 `blinky`，用于验证 board target、GPIO 栈和板载 LED alias 能在固定 Zephyr 基线下构建。
