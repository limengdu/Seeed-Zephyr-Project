# xiao_esp32c5

## English

This directory contains the placeholder baseline demo record for Seeed Studio
XIAO ESP32C5.

The pinned Zephyr v4.4.0 baseline does not provide a `xiao_esp32c5` board target
yet, so the demo is tracked as `unsupported` until a real XIAO target is
available in the selected Zephyr baseline.

## 中文

这个目录保存 Seeed Studio XIAO ESP32C5 的占位基线 demo 记录。

当前固定的 Zephyr v4.4.0 基线还没有 `xiao_esp32c5` board target，所以这个 demo 先记录为 `unsupported`。等选定 Zephyr 基线里有真实 XIAO target 后，再转为可构建 demo。
