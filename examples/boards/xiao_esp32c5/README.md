# xiao_esp32c5

## English

This directory contains board demos for Seeed Studio XIAO ESP32C5.

The baseline demo is `hello_world`. It builds for the upstream Zephyr target
`xiao_esp32c5/esp32c5/hpcore` (the high-performance core) and prints to the
USB serial console.

## 中文

这个目录保存 Seeed Studio XIAO ESP32C5 的开发板 demo。

基线 demo 是 `hello_world`。它面向上游 Zephyr target `xiao_esp32c5/esp32c5/hpcore`（高性能主核）构建，并通过 USB 串口控制台输出。
