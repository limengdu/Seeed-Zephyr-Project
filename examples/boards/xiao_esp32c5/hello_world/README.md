# xiao_esp32c5 hello_world

## English

This demo prints a heartbeat message on the Zephyr console. It is the baseline
demo for XIAO ESP32C5 and builds for `xiao_esp32c5/esp32c5/hpcore`.

Build from the repository root:

```sh
bash scripts/build-example.sh examples/boards/xiao_esp32c5/hello_world
```

## 中文

这个 demo 会在 Zephyr 控制台周期性打印心跳消息，是 XIAO ESP32C5 的基线 demo，构建目标为 `xiao_esp32c5/esp32c5/hpcore`。

从仓库根目录构建:

```sh
bash scripts/build-example.sh examples/boards/xiao_esp32c5/hello_world
```
