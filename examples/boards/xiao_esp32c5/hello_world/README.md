# xiao_esp32c5 hello_world

## English

This directory records the intended baseline demo for XIAO ESP32C5.

The selected Zephyr v4.4.0 baseline does not provide a `xiao_esp32c5` board
target, so build scripts report this demo as `UNSUPPORTED` until the target is
available in the selected Zephyr baseline.

## 中文

这个目录记录 XIAO ESP32C5 计划使用的基线 demo。

当前选择的 Zephyr v4.4.0 基线没有 `xiao_esp32c5` board target，所以构建脚本会把这个 demo 报告为 `UNSUPPORTED`。等选定 Zephyr 基线提供该 target 后再启用构建。
