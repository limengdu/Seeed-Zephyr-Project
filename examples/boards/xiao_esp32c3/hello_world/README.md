# xiao_esp32c3 hello_world

## English

This demo prints a heartbeat message on the Zephyr console. It is the baseline
demo for XIAO ESP32C3 because this board has no on-board LED.

Build from the repository root:

```sh
bash scripts/build-example.sh examples/boards/xiao_esp32c3/hello_world
```

## 中文

这个 demo 会在 Zephyr 控制台周期性打印心跳消息。XIAO ESP32C3 没有板载 LED，所以它用这个 demo 作为基线验证。

从仓库根目录构建:

```sh
bash scripts/build-example.sh examples/boards/xiao_esp32c3/hello_world
```
