# xiao_esp32c3

## English

This directory contains board demos for Seeed Studio XIAO ESP32C3.

The baseline demo is `hello_world` because XIAO ESP32C3 does not provide an
on-board LED for the Zephyr `blinky` pattern.

## 中文

这个目录保存 Seeed Studio XIAO ESP32C3 的开发板 demo。

基线 demo 是 `hello_world`，因为 XIAO ESP32C3 没有板载 LED，不适合使用 Zephyr 的 `blinky` 模式作为最小验证。
