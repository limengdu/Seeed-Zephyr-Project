# xiao_nrf54lm20a blinky

## English

This demo toggles the board LED through Zephyr GPIO. It is the baseline demo for
Seeed Studio XIAO nRF54LM20A.

Build from the repository root:

```sh
bash scripts/build-example.sh examples/boards/xiao_nrf54lm20a/blinky
```

## 中文

这个 demo 通过 Zephyr GPIO 翻转板载 LED，是 Seeed Studio XIAO nRF54LM20A 的基线 demo。

从仓库根目录构建:

```sh
bash scripts/build-example.sh examples/boards/xiao_nrf54lm20a/blinky
```
