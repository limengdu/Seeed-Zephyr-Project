# scripts/lib

## English

This directory contains shared shell helpers used by repository setup and build
scripts.

Files here should stay small and reusable. Put a function here only when more
than one script needs the same behavior.

## 中文

这个目录保存仓库 setup 和 build 脚本共用的 shell 辅助函数。

这里的文件应保持小而可复用。只有当多个脚本都需要同一段行为时，才把函数放到这里。
