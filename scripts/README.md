# scripts

## English

This directory contains user-facing helper scripts.

Scripts should make repository examples, projects, setup, build, flash, or
validation easier to run. They should point users back to repository assets
rather than making upstream Zephyr samples the main workflow.

## 中文

这个目录保存面向用户的辅助脚本。

脚本应让仓库示例、项目、环境搭建、构建、烧录或验证更容易运行。它们应把用户引回本仓库资产，而不是把上游 Zephyr samples 当成主要工作流。
